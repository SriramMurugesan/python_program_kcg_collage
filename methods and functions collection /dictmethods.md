# Full Dictionary Methods
## Adding & Updating Elements
update(dict)   → Update dictionary with key/value pairs
setdefault(k)  → Insert key with a value of default if key is not in dict
## Removing Elements
pop(k)         → Remove item by key and return its value
popitem()      → Remove and return the last inserted key-value pair
clear()        → Remove all items
## Accessing Elements
get(k)         → Return the value for key
keys()         → Return a view object of all keys
values()       → Return a view object of all values
items()        → Return a view object of all (key, value) tuple pairs
## Copy
copy()         → Create shallow copy
fromkeys(keys) → Create dictionary from sequence of keys
