# Full Set Methods
## Adding Elements
#### add(x)         → Add single element
#### update(iter)   → Add multiple elements
## Removing Elements
#### remove(x)      → Remove element (raises error if not found)
#### discard(x)     → Remove element (no error if not found)
#### pop()          → Remove and return an arbitrary element
#### clear()        → Remove all elements
## Mathematical Operations (Set Algebra)
#### union(set)            → Return union of sets
#### intersection(set)     → Return intersection of sets
#### difference(set)       → Return difference of sets
#### symmetric_difference()→ Return symmetric difference
## Subset & Superset Checking
#### issubset(set)         → Check if subset
#### issuperset(set)       → Check if superset
#### isdisjoint(set)       → Check if sets have no items in common
## Copy
#### copy()         → Create shallow copy
